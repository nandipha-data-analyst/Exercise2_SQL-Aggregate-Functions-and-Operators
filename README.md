# Exercise 2: SQL Aggregate Functions and Operators

## Project Overview
This repository contains a structured set of SQL exercises focusing on **Aggregate Functions** and **Logical Operators**. The purpose of this project is to demonstrate foundational data-filtering, grouping, and metrics-summarisation techniques required for professional data analysis. 

By applying these SQL methods, we can transform raw, granular database rows into high-level business insights (such as total sales, averages, and conditional segmentations).

## Key Learning Objectives & Core Concepts
This project provides hands-on practice with the following SQL mechanisms:

### 1. Aggregate Functions
* **`COUNT()`**: Determining total transactional volumes or customer reach.
* **`SUM()`**: Aggregating raw financial data to track cumulative key metrics (e.g., total revenue).
* **`AVG()`**: Computing arithmetic means to understand typical performance distribution.
* **`MIN()` & `MAX()`**: Identifying extreme data bounds, such as lowest margins or peak historical transaction values.

### 2. Grouping & Subsetting
* **`GROUP BY`**: Categorising aggregated outputs across specific dimensional buckets (e.g., performance by category or country).
* **`HAVING`**: Applying conditional filters to aggregate sets—specifically used for tracking specific variations or specific thresholds.

### 3. Core Operators
* **Logical Operators**: `AND`, `OR`, `NOT` for defining multi-layered filtering criteria.
* **Comparison & Range Operators**: Using `>`, `<`, `=`, `BETWEEN`, and `IN` to narrow data sets down cleanly.
* **Pattern Matching**: Employing `LIKE` and wildcards (`%`, `_`) to search string segments.
